# Software de Biblioteca Universitaria

## Descripción
Este software de biblioteca está diseñado para la gestión eficiente de préstamos y reservas de material bibliográfico en una universidad. Su objetivo es facilitar el acceso y control de los recursos de la biblioteca para diferentes tipos de usuarios: estudiantes, profesores, empleados, bibliotecarios y administradores. 

## Funcionalidades

### Funciones de los usuarios
- Consultar el catálogo de materiales disponibles.
- Realizar reservas de material bibliográfico.
- Ver el historial de reservas realizadas.
- Consultar los préstamos activos.
- Registrarse en la plataforma y acceder mediante un sistema de autenticación.

### Funciones del bibliotecario
- Visualizar las reservas pendientes.
- Aceptar o rechazar solicitudes de reserva de material.
- Cuando una reserva es aceptada, se genera automáticamente un préstamo asociado.

### Funciones del administrador
- En esta fase del desarrollo, el administrador aún no tiene funcionalidades activas, pero se espera que pueda gestionar materiales, préstamos, reservas y usuarios en futuras versiones.

## Alcance actual del software
- Implementación del sistema de autenticación (registro y login de usuarios).
- Consulta de material bibliográfico disponible.
- Realización de reservas por parte de los usuarios.
- Visualización del historial de reservas y préstamos.
- Gestión de reservas por parte del bibliotecario:
  - Visualización de reservas pendientes.
  - Aceptación o rechazo de reservas.
  - Creación automática de un préstamo al aceptar una reserva.

El software se encuentra en una fase inicial, con funcionalidades enfocadas en la autenticación de usuarios, la consulta de materiales y la gestión de reservas por parte de los bibliotecarios. En futuras actualizaciones, se incluirán nuevas opciones como la renovación de préstamos, la devolución de materiales y una mayor capacidad de gestión para los administradores.
